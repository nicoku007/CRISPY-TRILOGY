CRISPY TRILOGY: Crispy-Heretic + Crispy-Hexen + Crispy-Strife

INTRODUCTION:

Crispy Trilogy is a launcher created using C# Windows Forms, designed 
to unify the source ports Crispy Heretic, Crispy Hexen, and Crispy 
Strife. We could say it is something like a home-grown and modest 
version of the official Heretic + Hexen release, but structured as 
a trilogy and built for a source port. Each session has its own parameters, 
multiplayer settings, WAD browser among other things.

Note: The latest version of Crispy Heretic is compatible with the new 
expansion episode "Faith Renewed" (heretic_fr.wad); however, for it to 
work, you must use the heretic.wad file from the official Heretic + Hexen 
collection. If any other heretic.wad file is used, the episode will 
experience severe graphical distortion.


HOW TO USE AND INSTALLATION:

It is a simple launcher to use. Inside the zip file, you will find 
the main directory Crispy-Trilogy which contains the launcher along 
with three subfolders: crispy-heretic, crispy-hexen, and crispy-strife. 
All you have to do is place the corresponding source port files 
including all their required DLLs and configuration assets along with 
the game WADs inside these subfolders. The main Crispy-Trilogy.exe 
file must sit right next to these folders to detect the games properly. 
There is no need to move anything else.
